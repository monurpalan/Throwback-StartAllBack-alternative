# Windows Vista images

Original images from Windows Vista's `aero.msstyles` for the Vista start menu
style, embedded into `throwback.exe`: the orb (`StartBottom::Button`, per
DPI), the `StartPanel` parts (program pane, All Programs, places column,
search box, separators, arrows, power and lock buttons, picture frame) and
the start menu list hovers. The theme stores premultiplied alpha; these
copies are straight alpha, nothing else was changed.

The images belong to Microsoft. Without this folder Throwback still builds.
