# Modern images

| File | Source |
|---|---|
| `w81-logo-*.png`, `w81-glow-*.png` | Windows 8.1 `twinui.dll` images 11701-11723: the Start button's logo and hover glow, per DPI |
| `w10-logo-*.png` | Windows 8.1 `twinui.dll` images 11702-11714: the same flat logo small, as Windows 10's Start button shows it |
| `w11-logo-*.png` | The Windows 11 logo (Wikimedia Commons), at the taskbar's sizes per DPI |

Windows 10 and 11 draw their start menus with the Segoe MDL2 Assets and
Segoe Fluent Icons fonts, which come with Windows; nothing else is needed.
The images belong to Microsoft. Without this folder Throwback still builds.
